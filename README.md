# Clicky

تحكم في سلايدات البريزنتيشن بإيماءات إيدك قدام الكاميرا (ويندوز).
Control your presentation slides with hand gestures in front of your webcam (Windows).

Clicky بيتتبع إيدك عن طريق [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)،
وبيعرف اليمين من الشمال، وبيبعت ضغطات كيبورد (← / → / F5 / Esc / B) للبرنامج المفتوح.
عشان كده بيشتغل مع PowerPoint و Google Slides و Keynote على الويب و PDF وغيرهم.

## التشغيل

1. نزّل `Clicky.exe` من آخر [Release](../../releases)، أو من artifacts بتاعة آخر build ناجح في [Actions](../../actions).
2. شغّله، وهتلاقي أيقونة جنب الساعة وصفحة الإعدادات هتفتح في المتصفح (`http://127.0.0.1:8765`).
3. افتح العرض وخلّي نافذته هي النشطة (اضغط عليها مرة)، وابدأ تشاور.

## الإيماءات الافتراضية

| الإيماءة | الأمر |
|---|---|
| لمسة سريعة إبهام + سبابة باليد اليمين | السلايد اللي بعده |
| لمسة سريعة إبهام + سبابة باليد الشمال | السلايد اللي قبله |
| لمستين ورا بعض بسرعة | تشغيل/إنهاء العرض |
| سحب الكف المفتوح ناحية الشمال (وضع بعيد) | السلايد اللي بعده |
| سحب الكف المفتوح ناحية اليمين (وضع بعيد) | السلايد اللي قبله |
| كف مفتوح ثابت 1.5 ثانية | شاشة سودا |
| قبضة ثانية | قفل/فتح التحكم |

كل الأوامر تقدر تغيرها من صفحة الإعدادات.

### إزاي بيفرق بين الإيماءة والحركة العادية؟

- **اللمسة لازم تبقى سريعة:** الصوابع يتلمسوا ويفترقوا في أقل من 0.6 ثانية، والإيد ثابتة تقريبًا. لو مسكتهم أكتر أو إيدك بتتحرك، اللمسة بتتلغي.
- **قفل الصوابع في قبضة مش لمسة:** لو الصوابع قربوا من بعض وانت بتقفل إيدك، مش بتتحسب.
- **السحب لازم يبقى سريع وأفقي:** والكف مفتوح، وبعده رجوع الإيد بيتجاهل لمدة ثانية.
- **فترة انتظار:** بعد كل أمر فيه 0.8 ثانية مفيش فيها أوامر تانية.
- **القفل:** اعمل قبضة ثانية عشان تقفل التحكم وانت بتشرح، واعملها تاني عشان تفتحه.
- **الإيدين الصغيرة أوي** (حد بعيد في الخلفية) بتتجاهل.

### قريب ولا بعيد؟

- **قريب** (لحد مترين تقريبًا): لمسة الصوابع أدق وأريح.
- **بعيد**: الكاميرا بتشوف الصوابع صغيرة، فاستخدم السحب بالكف واختار دقة 1920×1080.
- **الاتنين** (الافتراضي): الطريقتين شغالين مع بعض.

## التطوير

```bash
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements-dev.txt
python scripts/fetch_model.py
pytest
python -m clicky              # --no-tray --no-browser --dry-run متاحين
pyinstaller --noconfirm clicky.spec   # dist\Clicky.exe
```

الإعدادات واللوج بيتحفظوا في `%APPDATA%\Clicky\`.

| الملف | الوظيفة |
|---|---|
| `clicky/gestures.py` | تحويل نقط اليد لإيماءات (اللمسة، اللمستين، القبضة، الكف، السحب) |
| `clicky/tracker.py` | تتبع اليد بـ MediaPipe |
| `clicky/app.py` | الكاميرا وتنفيذ الأوامر والمعاينة |
| `clicky/actions.py` | إرسال ضغطات الكيبورد |
| `clicky/web.py` و `clicky/static/settings.html` | صفحة الإعدادات |
| `clicky/tray.py` | أيقونة شريط المهام |

صفحة الإعدادات شغالة على `127.0.0.1` بس، يعني محدش على الشبكة يقدر يفتحها.
